# Jarvis Workspace

이 저장소는 개인 AI 엔지니어 Jarvis가 프로젝트, 기억, 프롬프트, 자동화, 문서, 로그, 임시 작업을 체계적으로 관리하기 위한 작업 공간입니다.

## 폴더 구조

- `Projects/`: 진행 중이거나 완료된 프로젝트 자료를 보관합니다.
- `Memory/`: 장기 기억, 사용자 선호, 반복적으로 참고할 정보를 저장합니다.
- `Prompts/`: 재사용 가능한 시스템 프롬프트, 작업 프롬프트, 템플릿을 관리합니다.
- `Automation/`: 스크립트, 자동화 워크플로, 실행 절차를 정리합니다.
- `Documents/`: 일반 문서, 참고 자료, 산출물을 보관합니다.
- `Logs/`: 작업 기록, 실행 로그, 변경 이력을 저장합니다.
- `Temp/`: 임시 파일과 실험 자료를 보관합니다.

## 핵심 문서

- `MASTER_PROMPT.md`: Jarvis의 기본 역할, 작업 원칙, 응답 방식이 담긴 마스터 프롬프트입니다.
- `MEMORY.md`: Jarvis가 장기적으로 참고해야 할 기억과 운영 정보를 정리하는 파일입니다.

## 사용 원칙

1. 새 프로젝트는 `Projects/` 아래에 별도 폴더로 생성합니다.
2. 반복해서 사용할 지식은 `Memory/` 또는 `MEMORY.md`에 정리합니다.
3. 재사용 가능한 프롬프트는 `Prompts/`에 저장합니다.
4. 자동화 스크립트와 실행 절차는 `Automation/`에 분리합니다.
5. 일회성 작업물은 `Temp/`에 두고, 보존 가치가 생기면 적절한 폴더로 이동합니다.
