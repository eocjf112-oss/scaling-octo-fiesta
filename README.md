# Jarvis Workspace

이 저장소는 개인 AI 엔지니어링 비서인 Jarvis를 위한 기본 작업공간입니다.

## 목적

Jarvis Workspace는 프로젝트 진행, 장기 기억, 프롬프트 관리, 자동화 작업, 문서 보관, 로그 기록, 임시 파일 관리를 한곳에서 다루기 위한 구조입니다.

## 폴더 구조

- `Projects/`: 진행 중이거나 완료된 프로젝트별 작업 자료를 보관합니다.
- `Memory/`: Jarvis가 참고해야 할 장기 메모리, 사용자 선호, 반복 지식 등을 정리합니다.
- `Prompts/`: 재사용 가능한 시스템 프롬프트, 작업 프롬프트, 템플릿을 저장합니다.
- `Automation/`: 스크립트, 워크플로, 자동화 아이디어와 실행 파일을 관리합니다.
- `Documents/`: 일반 문서, 참고 자료, 회의 노트, 정책 문서를 보관합니다.
- `Logs/`: 작업 기록, 실행 결과, 오류 로그, 변경 이력을 저장합니다.
- `Temp/`: 임시 실험 파일, 중간 산출물, 빠른 테스트 자료를 둡니다.

## 핵심 문서

- `MASTER_PROMPT.md`: Jarvis의 기본 역할, 운영 원칙, 작업 방식이 정의된 마스터 프롬프트입니다.
- `MEMORY.md`: Jarvis가 장기적으로 기억해야 할 정보를 정리하는 중앙 메모리 파일입니다.

## 사용 원칙

1. 중요한 결정과 반복되는 지식은 `MEMORY.md`에 기록합니다.
2. 재사용 가치가 있는 지시문은 `Prompts/`에 분리합니다.
3. 프로젝트별 산출물은 `Projects/` 아래에 별도 폴더로 관리합니다.
4. 자동화 가능한 작업은 `Automation/`에 정리하고 개선합니다.
5. 임시 파일은 `Temp/`에만 두고, 필요 없어지면 정리합니다.
