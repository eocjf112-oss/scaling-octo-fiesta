# 🤖 Jarvis AI 워크스페이스

> **"당신의 개인 AI 엔지니어, Jarvis입니다."**

---

## 📌 개요

이 워크스페이스는 **Jarvis AI 시스템**의 중앙 허브입니다.
프로젝트 관리, 기억 저장, 자동화 스크립트, 프롬프트 라이브러리, 문서, 로그 등 모든 작업을 체계적으로 관리합니다.

---

## 🗂️ 폴더 구조

```
Jarvis/
│
├── Projects/       # 진행 중인 프로젝트 및 코드베이스
├── Memory/         # AI 장기 기억 및 컨텍스트 저장소
├── Prompts/        # 재사용 가능한 프롬프트 라이브러리
├── Automation/     # 자동화 스크립트 및 워크플로우
├── Documents/      # 문서, 보고서, 참고 자료
├── Logs/           # 시스템 로그 및 실행 기록
├── Temp/           # 임시 파일 및 작업 공간
│
├── README.md           # 이 파일 — 워크스페이스 안내
├── MASTER_PROMPT.md    # Jarvis의 핵심 행동 지침
└── MEMORY.md           # Jarvis의 현재 기억 및 컨텍스트
```

---

## 📁 폴더 설명

### 🔷 Projects (프로젝트)
진행 중이거나 완료된 모든 프로젝트가 저장됩니다.
각 프로젝트는 별도의 하위 폴더로 구성되며, 코드, 설계 문서, 요구사항 등이 포함됩니다.

### 🧠 Memory (기억)
Jarvis의 장기 기억 저장소입니다.
이전 대화, 학습된 선호도, 반복 작업 패턴, 사용자 설정 등이 기록됩니다.
AI가 컨텍스트를 유지하는 데 핵심적인 역할을 합니다.

### 💬 Prompts (프롬프트)
자주 사용하는 프롬프트 템플릿이 보관됩니다.
역할별, 작업별로 분류하여 효율적인 AI 대화를 지원합니다.
예: 코드 리뷰 프롬프트, 글쓰기 프롬프트, 분석 프롬프트 등.

### ⚙️ Automation (자동화)
반복 작업을 처리하는 스크립트와 워크플로우가 저장됩니다.
Python 스크립트, 쉘 스크립트, API 연동, 예약 작업 등을 포함합니다.

### 📄 Documents (문서)
프로젝트 관련 문서, 연구 자료, 보고서, 메모 등이 저장됩니다.
Markdown, PDF, Word 등 다양한 형식을 지원합니다.

### 📋 Logs (로그)
시스템 실행 기록, 오류 로그, 작업 이력이 저장됩니다.
문제 추적 및 성능 모니터링에 활용됩니다.

### 🗑️ Temp (임시)
임시 파일, 테스트 결과물, 단기 작업 파일이 저장됩니다.
주기적으로 정리되며, 중요한 파일은 적절한 폴더로 이동해야 합니다.

## 🚀 시작하기

1. `MASTER_PROMPT.md`를 읽고 Jarvis의 행동 원칙을 이해하세요.
2. `MEMORY.md`에서 현재 컨텍스트와 진행 상황을 확인하세요.
3. 새 프로젝트는 `Projects/` 폴더에 하위 폴더를 생성하여 시작하세요.
4. 반복되는 작업은 `Automation/`에 스크립트로 저장하세요.
