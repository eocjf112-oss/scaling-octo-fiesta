# Jarvis Workspace

이 작업공간은 개인 AI 비서인 Jarvis를 안정적으로 운영하기 위한 기본 구조입니다.
모든 설명과 운영 기준은 한국어를 기본으로 하며, 프로젝트 진행 기록, 장기 기억, 프롬프트 자산, 자동화 스크립트, 문서를 한곳에서 관리할 수 있도록 설계했습니다.

## 1. 작업공간 목적

Jarvis Workspace의 목적은 다음과 같습니다.

- 프로젝트별 산출물을 체계적으로 보관
- 사용자 선호, 규칙, 반복 업무를 기억 자산으로 누적
- 재사용 가능한 프롬프트를 표준화
- 자동화 스크립트와 운영 로그를 분리 관리
- 임시 파일과 영구 문서를 구분하여 작업 효율 향상

## 2. 폴더 구조

```text
Jarvis/
├── README.md
├── MASTER_PROMPT.md
├── MEMORY.md
├── JARVIS.txt
├── Projects/
├── Memory/
├── Prompts/
├── Automation/
├── Documents/
├── Logs/
└── Temp/
```

## 3. 폴더별 설명

### Projects
- 실제 업무, 실험, 고객 요청, 개발 과제별 작업 공간입니다.
- 프로젝트마다 하위 폴더를 만들어 소스, 메모, 결과물을 함께 보관하면 좋습니다.

예시:
```text
Projects/
└── client-dashboard/
    ├── src/
    ├── notes.md
    └── deliverables/
```

### Memory
- 장기적으로 유지해야 하는 지식을 저장합니다.
- 사용자 선호, 의사결정 기록, 반복 규칙, 업무 스타일, 자주 쓰는 명령 등을 정리합니다.

권장 분류:
- `user-preferences.md`
- `project-rules.md`
- `decision-log.md`

### Prompts
- 재사용 가능한 프롬프트 템플릿 저장소입니다.
- 역할별, 상황별, 업무 유형별 프롬프트를 정리합니다.

권장 분류:
- `coding-assistant.md`
- `meeting-summary.md`
- `research-brief.md`

### Automation
- 스크립트, 배치 작업, 워크플로 자동화 파일을 둡니다.
- 예: 백업 스크립트, 로그 정리 스크립트, 문서 생성 도구

### Documents
- 최종 문서, 운영 매뉴얼, 정책 문서, 요약 보고서를 저장합니다.
- 외부 공유용 자료와 내부 참고 문서를 함께 관리할 수 있습니다.

### Logs
- 작업 기록, 실행 로그, 오류 기록, 운영 히스토리를 저장합니다.
- 사람이 읽는 일일 로그와 기계가 출력하는 실행 로그를 분리하면 관리가 쉬워집니다.

### Temp
- 임시 생성 파일, 테스트 산출물, 정리 전 초안 등을 저장합니다.
- 주기적으로 비워도 되는 영역입니다.

## 4. 핵심 문서 설명

### MASTER_PROMPT.md
- Jarvis가 항상 따를 기본 운영 프롬프트입니다.
- 역할, 말투, 우선순위, 작업 방식, 응답 규칙을 한곳에 정의합니다.

### MEMORY.md
- Jarvis가 기억해야 하는 핵심 정보의 기본 양식입니다.
- 장기 기억을 일관된 구조로 업데이트하기 위한 기준 문서입니다.

### JARVIS.txt
- 전체 폴더 구조를 빠르게 확인하기 위한 간단한 트리 파일입니다.

## 5. 권장 운영 방식

1. 새 업무가 생기면 `Projects/` 아래에 프로젝트 폴더를 만듭니다.
2. 프로젝트 진행 중 반복되는 규칙이나 선호가 생기면 `Memory/` 또는 `MEMORY.md`에 반영합니다.
3. 잘 동작하는 프롬프트는 `Prompts/`에 템플릿으로 저장합니다.
4. 자동화가 가능해지면 관련 스크립트를 `Automation/`에 추가합니다.
5. 최종 문서는 `Documents/`, 임시 파일은 `Temp/`, 기록은 `Logs/`에 분리합니다.

## 6. 시작 체크리스트

- `MASTER_PROMPT.md`에 Jarvis의 역할과 응답 원칙을 정의한다.
- `MEMORY.md`에 사용자 선호와 작업 규칙을 누적한다.
- `Projects/` 아래에 현재 진행 중인 업무 폴더를 만든다.
- `Prompts/`에 자주 쓰는 템플릿을 정리한다.
- `Logs/`와 `Temp/`를 운영 목적에 맞게 주기적으로 정리한다.

## 7. 참고
