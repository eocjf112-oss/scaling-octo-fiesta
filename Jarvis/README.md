# Jarvis Workspace

이 디렉터리는 개인 AI 비서인 Jarvis를 안정적으로 운영하기 위한 기본 워크스페이스입니다.
모든 설명은 한국어 기준으로 작성되었으며, 프로젝트 진행, 기억 관리, 자동화, 문서 보관을 한곳에서 다룰 수 있도록 구성했습니다.

## 폴더 구조

```text
Jarvis/
├── Projects/
├── Memory/
├── Prompts/
├── Automation/
├── Documents/
├── Logs/
├── Temp/
├── README.md
├── MASTER_PROMPT.md
├── MEMORY.md
└── JARVIS.txt
```

## 각 폴더 설명

### 1. Projects
- 실제로 진행 중인 작업, 아이디어, 실험용 산출물을 보관하는 공간입니다.
- 프로젝트별로 하위 폴더를 만들어 관리하면 좋습니다.
- 예시:
  - `Projects/web-app`
  - `Projects/startup-ideas`
  - `Projects/research-notes`

### 2. Memory
- Jarvis가 장기적으로 참고해야 하는 핵심 정보와 사용자 선호를 저장하는 공간입니다.
- 반복해서 설명하고 싶지 않은 배경지식, 규칙, 고정 설정을 정리할 때 사용합니다.
- `MEMORY.md`와 함께 쓰면 가장 효율적입니다.

### 3. Prompts
- 자주 사용하는 프롬프트 템플릿, 역할 프롬프트, 업무 지시문을 저장하는 공간입니다.
- `MASTER_PROMPT.md`를 기준으로 목적별 프롬프트를 파생해서 관리할 수 있습니다.

### 4. Automation
- 스크립트, 워크플로우, 자동 실행 규칙, 체크리스트 등을 보관하는 공간입니다.
- Bash, Python, 노코드 자동화 문서 등 반복 작업을 줄이는 자산을 모아두는 용도입니다.

### 5. Documents
- 정책 문서, 회의 기록, 참고 자료, 설계 문서, 요약본 등을 정리하는 공간입니다.
- 사람이 읽는 문서를 체계적으로 보관하는 메인 문서함 역할을 합니다.

### 6. Logs
- 작업 로그, 실행 로그, 일일 기록, 오류 기록을 보관하는 공간입니다.
- Jarvis의 응답 이력 요약이나 자동화 실행 결과를 남기는 용도로도 적합합니다.

### 7. Temp
- 임시 파일, 초안, 테스트 출력물, 정리 전 자료를 잠시 두는 공간입니다.
- 정기적으로 비워서 워크스페이스를 깔끔하게 유지하는 것이 좋습니다.

## 핵심 문서 설명

### README.md
- 이 워크스페이스 전체 구조와 운영 방식을 설명하는 안내서입니다.

### MASTER_PROMPT.md
- Jarvis를 어떤 방식으로 동작시킬지 정의하는 기본 마스터 프롬프트입니다.
- 새 세션을 시작할 때 기준 프롬프트로 사용할 수 있습니다.

### MEMORY.md
- 사용자 정보, 선호도, 현재 진행 상황, 중요한 결정사항을 누적해서 관리하는 기억 문서입니다.

## 추천 운영 방식

1. 새로운 작업을 시작할 때 `Projects/`에 프로젝트 폴더를 만듭니다.
2. 자주 반복되는 지시문은 `Prompts/`에 저장합니다.
3. 장기적으로 기억해야 할 내용은 `MEMORY.md`와 `Memory/`에 정리합니다.
4. 실행 결과나 오류는 `Logs/`에 기록합니다.
5. 임시 초안은 `Temp/`에서 정리한 뒤 필요한 위치로 옮깁니다.

## 기존 파일 안내

- `JARVIS.txt`는 초기 폴더 아이디어를 간단히 정리한 스케치 파일입니다.
- 현재 워크스페이스는 그 구조를 보다 실사용 중심으로 정리한 버전입니다.

## 시작 체크리스트

- `MASTER_PROMPT.md`를 열어 Jarvis의 역할과 응답 원칙을 확인합니다.
- `MEMORY.md`에 사용자 선호와 현재 프로젝트 상태를 기록합니다.
- 새 작업은 `Projects/`에 폴더를 만들고 시작합니다.

이제 이 워크스페이스를 기반으로 Jarvis를 개인 운영 시스템처럼 확장해 나갈 수 있습니다.
