# MEMORY

이 문서는 Jarvis가 장기적으로 참고해야 할 정보를 정리하는 기억 허브입니다.
반복 설명을 줄이고, 대화 품질을 높이며, 작업 맥락을 빠르게 복원하기 위한 목적입니다.

---

## 사용 원칙

1. 장기적으로 중요한 정보만 기록합니다.
2. 일시적인 메모는 `Temp/`에 두고, 확정된 내용만 여기로 옮깁니다.
3. 사실, 선호, 진행 상태, 의사결정을 구분해서 기록합니다.
4. 정보가 바뀌면 오래된 내용을 지우기보다 최신 상태를 함께 표시합니다.
5. 민감한 정보는 필요한 범위만 최소한으로 기록합니다.

## 추천 운영 방법

- 새로 확인된 사용자 선호는 즉시 `사용자 선호` 섹션에 반영합니다.
- 진행 중인 일은 `현재 프로젝트` 표에서 상태를 갱신합니다.
- 중요한 방향 전환은 `중요한 의사결정 기록`에 남깁니다.
- 오래된 메모는 삭제하기보다 최신 상태를 명확히 적어 혼동을 줄입니다.
